# Solar System Explorer

An interactive web page for exploring the planets of our solar system and dwarf planet Pluto through an animated, 3D-style interface.

---

## About the Project
Solar System Explorer is a single-page site built with only **HTML** and **CSS**. There is no JavaScript and no build step: the interaction is driven by radio buttons and CSS selectors.

---

## Features
- 🌍 **Interactive UI**: Pick a planet from the menu to fly to it and see its moons.
- ☀️ **Animated Solar System**: A 3D-style view with rotating planet surfaces.
- 📖 **Detailed Information Panels**: Each planet has an article with a description and fun facts.
- 📱 **Responsive Design**: The layout adapts to phones and desktops.
- ⌨️ **Keyboard Support**: `Tab` moves between the planet menu and Read More. Arrow keys switch planets, and `Space` opens an article. Use the arrow keys to close it again.
- 🎞️ **Reduced Motion**: Animations are turned off for visitors who prefer reduced motion.

---

## Technologies Used
- **HTML5** – Page structure and content
- **CSS3** – Styling, animations, interactive effects
- **Google Fonts** – Montserrat typeface

---

## Installation
1. Clone the repository:
   ```bash
   git clone git@github.com:Jjumaaa/SolarSystem.git
   ```
2. Open `index.html` in a browser. An internet connection is needed for the font and some remotely hosted images.
